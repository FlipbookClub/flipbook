- [ ] **TASK-127** — EPUB offline caching: on rental, download EPUB to secure device storage; render from cache without network.
- [ ] **TASK-128** — PD catalog ingestion pipeline: Convex script that pulls Standard Ebooks metadata + EPUB files, uploads to Convex storage, creates `books` rows with `source: "public_domain"`, `isPublished: true`. Target: 500 titles ingested by end of Phase 11.
- [ ] **TASK-129** — Catalog browse screen: editorial shelves (New this week, Nigerian indie, Classics, Specials, Trending in your genres). Horizontal scrollers of `BookCard`.
- [ ] **TASK-130** — Book detail screen: cover, title, author, description, band price, "X friends are reading this," Rent + Preview CTAs.
- [ ] **TASK-131** — Catalog search + filter: Convex `searchIndex` on `books.title`; filter by band, genre, source; pagination.
- [ ] **TASK-132** — Rentals mutation: `createRental` — validates Pro/Free, computes `pricePaid` (with 15% Pro discount on B/C/D, free for Pro on A), assigns `expiresAt`, generates `watermarkSeed`, returns rental ID + signed EPUB URL. Idempotent on `paystackReference`.

- [ ] **TASK-137** — Deep links: catalog title, book detail, and rental checkout all deep-linkable via `flipbook://book/:id` etc.

## Phase 13 — v2 Audio Reader Pipeline

**Goal:** neural-TTS audio narration pre-generated at book ingestion; Pro users can listen to any catalog book that isn't opted out.

**Duration estimate:** 2-3 weeks.

**Dependencies:** Phase 11 catalog live, Phase 12 Pro entitlement live.

### Tasks

- [ ] **TASK-148** — Provider-agnostic TTS abstraction in `convex/audio.ts`: interface with `generateAudio(text, voice, provider)`; implementations for OpenAI TTS and ElevenLabs.
- [ ] **TASK-149** — TTS ingestion scheduled action: when a book transitions to `isPublished: true` and `audioOptOut: false`, schedule a per-chapter generation job; upload MP3s to Convex storage; write `audioAssets` rows; transition `books.audioStatus` `pending → ready`.
- [ ] **TASK-150** — Chapter chunking: split EPUB by chapter (or 5,000-character segments if chapters are absent); one MP3 per chunk.
- [ ] **TASK-151** — Audio playback UI in reader: play/pause, chapter nav, 15s skip, playback speed. Pro-only gate.
- [ ] **TASK-152** — Audio streaming from Convex storage: signed URL per chapter, cached client-side per rental.
- [ ] **TASK-153** — Author audio opt-out: term-sheet checkbox at signing → `authorAccounts.audioOptOut` (or per-book `books.audioOptOut`). Opted-out books skip TTS ingestion and never show play button.
- [ ] **TASK-154** — Specials premium audio: for books flagged `isSpecial`, re-ingest with ElevenLabs voices; `books.audioNarrator: "elevenlabs"`.
- [ ] **TASK-155** — Cost tracking: log each TTS generation with provider + character count + cost estimate; expose to admin dashboard for month-over-month budget review.
- [ ] **TASK-156** — Ingestion failure handling: retry once at 6h; alert admin if it fails twice; book stays readable in text, audio button hidden.

**Acceptance:** a book published today has audio ready to play within 30 min. Pro users can listen; Free users see a "Pro required" affordance. Opted-out books have no audio. Cost per book under $8 for OpenAI, under $60 for ElevenLabs.

## Phase 14 — v2 Author Onboarding + Royalty Ops

**Goal:** an African indie author can sign the term sheet, upload a book, get it published to the catalog, and receive a monthly statement + payout without a founder touching the pipeline.

**Duration estimate:** 3-4 weeks.

**Dependencies:** Phase 11 catalog live, Phase 16 payment rails live (for author payouts).

### Tasks

- [ ] **TASK-157** — Author signup form (in-app or hosted web page): legal name, pen name, email, country, payout currency, bank/PayPal/Wise details. Creates `authorAccounts` row.
- [ ] **TASK-158** — Inline term-sheet display + click-to-agree: v1 term-sheet text from `docs/supply/author-term-sheet.md`; signature captures timestamp + IP. Writes `termSheetVersion: "v1"`, `signedAt`.
- [ ] **TASK-159** — Author book upload flow: EPUB (max 30MB), cover image (max 5MB), title, description, genres, language, audio opt-in. Book saved as `isPublished: false`.
- [ ] **TASK-160** — Editorial review admin screen: list of pending books; admin previews cover + description + first pages; assigns rental band; publishes (`isPublished: true`, triggers TTS ingestion).
- [ ] **TASK-161** — `bookAuthors` join management: single-author books auto-populate `revenueSharePct: 70`. Co-authored works require manual admin allocation summing to 70.
- [ ] **TASK-162** — Monthly royalty statement cron: runs 00:05 UTC on the 1st of each month. For each active author: aggregates rentals in previous calendar month, computes gross + author share (respecting `bookAuthors.revenueSharePct`), applies FX for USD payouts, writes `royaltyStatements` row with `status: "finalized"`.
- [ ] **TASK-163** — Statement email generation: HTML email with period, rental count, gross, share, payout amount, payout method, expected payout date. Sends by the 15th. Uses `convex/lib/emailAssets.ts` logo lockup.
- [ ] **TASK-164** — Payout initiation (Paystack Transfers for NGN): creates a Paystack Transfer for the statement amount; writes `payouts` row with `method: "paystack"`, `status: "initiated"`.
- [ ] **TASK-165** — Payout initiation (Wise for USD): Wise API integration; creates recipient if not yet cached; initiates transfer; writes `payouts` row.
- [ ] **TASK-166** — Payout status webhook handlers: Paystack + Wise; update `payouts.status`, `royaltyStatements.status` to `"paid"` on success.
- [ ] **TASK-167** — Author dashboard: books, MTD earnings, past statements (downloadable), payout status.
- [ ] **TASK-168** — Book pullout flow: author-initiated 30-day pullout notice via a Settings action; sets book to `isRemoved: true` at the pullout date; no new rentals; existing rentals expire normally.
- [ ] **TASK-169** — Founding-30 tracking: `isFoundingCohort: true` on the first 30 signed authors; consider a founding-cohort bonus (80/20 split for first 6 months) — per-author negotiation, stored as a JSON blob on `authorAccounts` if used.
- [ ] **TASK-170** — Statement dry-run testing: synthetic dataset of 5 authors × 3 books × varied rental counts; verify statement generation, email, and payout initiation end-to-end BEFORE the first real author is on the platform.

**Acceptance:** a synthetic author with 12 rentals in a month receives a correct statement email by the 15th and a Paystack Transfer initiated by the 17th; real author signing flow is friction-free (under 10 minutes end-to-end).
