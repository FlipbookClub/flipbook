Course communities

Every screen and state for stories 12.1 to 12.4, for lecturers who want a class reading the set text: create a course and invite by email, set a reading list, see progress as totals, and close at term end. Flows read left to right in Flip; key screens repeat in Light and Dark, then in Classic and on Android.

12.4 · Lecturer

Manage the class, and close at term end

After the end date the course is closed to new students, and the class keeps its books and highlights. Manage has no grading, attendance or video entry, so nothing suggests they’re coming. If a lecturer asks support for them, the answer is: “Use your classroom tool for that, and Flipbook for the reading.”
